# Ícones SVG

`src/paths.ts` define nomes e paths tipados; `src/web.tsx` usa SVG inline e `src/native.tsx` usa react-native-svg. Logo vetorial recriado a partir da referência. Props `name`, `size`, `color`, `label`. `npm run typecheck -w @urbanizago/icons`. Sem variáveis próprias; iconografia em nomes ingleses, cores por tema.
