# Decisões arquiteturais

- **Monorepo npm workspaces**: quatro apps e quatro pacotes. Um único clone e uma versão coordenada. Dois projetos Expo têm pacote Android, slug, esquema e porta distintos para públicos diferentes. Não duplicamos gestão: `packages/app-ui/src/admin.tsx` contém as telas administrativas usadas por React Native e React Native Web, com adaptadores de mapas, ícones, exportação e navegação. Web mantém React + Vite, React Router e Recharts; mobile React Navigation.
- **API**: Express 5, TypeScript strict, Prisma 6 e PostgreSQL 16. Módulos por domínio; algumas rotas concentram controller e serviço no mesmo arquivo para simplificar o bootstrap. A separação completa controller/service/repository do prompt ainda deve ser refinada. Sem PostGIS: comparação por Haversine com recorte de categoria e janela temporal, locks transacionais PostgreSQL; avaliar PostGIS para escala municipal alta.
- **Autenticação**: JWT curta duração vinculado a sessão; refresh opaco de 32 bytes aleatórios com hash e rotação, cookie httpOnly no web e SecureStore no mobile. Login é restrito ao papel do aplicativo; banido recebe sessão limitada para consultar e recorrer.
- **MinIO privado**: fotos enviadas via SDK S3. URLs assinadas pela API (HMAC) expiram após 15 minutos e são resolvidas pelo cliente; servidor lê o objeto do bucket. A assinatura é autorização temporária por posse do link. Não é necessário abrir MinIO na rede local. Links não devem ser armazenados.
- **Jobs**: outbox PostgreSQL com leasing e retries; `node-cron` a cada 15s para e-mail/push e a cada 5 min para manutenção. Entrega ao menos uma vez, SMTP pode duplicar após falha. Ranking mensal consulta o livro-razão por início de mês UTC, sem materialização.
- **Google Maps**: credenciais do operador, fallback de lista quando não configuradas. No web, círculos translúcidos sobrepostos representam concentração espacial; aproximação visual, não heatmap de densidade por kernel. Mobile utiliza Heatmap nativo com Google provider; suporte depende do dispositivo/SDK.
- **Moderação**: sanções administradas por gestor, um recurso por sanção, anexos opcionais privados. A progressão automática de penalidades é deixada para revisão humana; o histórico é usado para decidir aplicação. A configuração de raio/janela incide sobre duplicatas; não há gatilhos de punição automática.
- **Exclusão**: confirmação por senha e código enviado por e-mail, anonimização imediata sem período de arrependimento, preserva ocorrências e auditoria não nominal. Administrador exclui contas cidadãs com motivo. Exclusão de administradores via procedimento operacional com substituto; não há interface administrativa de exclusão própria. Contas banidas/suspensas podem solicitar exercício de direitos por atendimento humano.
- **Design**: verde #08783E, sidebar #142838, cards arredondados, ícones próprios SVG; logo reconstruído geometricamente por não haver vetor original. Interface adaptativa inspirada na referência, não pixel-perfect.
- **Versões**: Node 22, Expo SDK 54, React 19, RN 0.81. A compatibilidade exata dos pacotes não pôde ser instalada/verificada aqui. As versões serão consolidadas após `npm install` e `expo install --fix`, com lockfile versionado.
